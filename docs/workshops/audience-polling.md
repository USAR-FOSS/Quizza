# Audience Polling Workshop

## Overview

This workshop demonstrates how a facilitator can collect audience feedback using four existing question types: Poll, Word cloud, Scale, and Open text.

**Workshop theme:** Improving group study sessions

**Suggested duration:** 15 to 20 minutes

**Purpose:** Help participants share preferences, identify common distractions, rate their confidence, and suggest improvements.

## Before the workshop

1. Open the quiz builder and create a new quiz.
2. Add the four questions below in the given order.
3. Save the quiz.
4. Start a live session and share its join code or link with participants.
5. Ask participants to join using their own devices.

## Workshop questions

### 1. Poll: What should we improve in our group study sessions?

Add these options:

- Better planning
- Staying focused
- Asking questions
- Revising together

Poll questions are for collecting preferences. They are not scored, so do not mark a correct answer.

**Facilitator action:** Read the question aloud and allow participants to select an option. Use the responses to introduce the next discussion.

### 2. Word cloud: What is one word that describes your biggest study distraction?

Set **Entries per player** to `1`.

**Facilitator action:** Invite participants to submit one short word. Discuss repeated themes in the word cloud. More frequently submitted words appear larger.

### 3. Scale: How confident are you about applying one new study strategy?

Set the scale from `1` to `5`.

- Low label: Not confident
- High label: Very confident

**Facilitator action:** Ask each participant to choose a rating. Use the resulting scale aggregate to discuss the group's confidence.

### 4. Open text: What is one small change that would make our next study session more useful?

**Facilitator action:** Invite participants to submit a short suggestion. Review the responses and identify practical ideas for the next session.

## Participant walkthrough

1. Open the session link or enter the join code provided by the facilitator.
2. Enter the requested participant details, if any, and join the session.
3. Wait for the facilitator to display the active question.
4. Select an option for the Poll question and submit.
5. Enter a short word for the Word cloud question and submit.
6. Select a number on the Scale question and submit.
7. Type a suggestion for the Open text question and submit.

Participants should follow the on-screen instructions and wait for the next question when the facilitator advances the session.

## Keyboard-friendly participation

Participants can use the keyboard instead of a mouse:

- Press `Tab` to move to the next interactive control.
- Press `Shift + Tab` to move to the previous control.
- Use `Enter` or `Space` to activate a focused button or selectable control.
- Use the arrow keys when the focused control supports keyboard selection.
- Use `Tab` to reach text fields, type the response, and move to the submit control.
- Check that focus is visible before activating a control.

The exact keys available for selecting an answer depend on the focused control and browser.

## Facilitator checklist

### During the session

- Confirm that participants have joined.
- Display one question at a time.
- Give participants enough time to submit responses.
- Review the available host-side response summaries.
- Explain the results without identifying participants unnecessarily.

### After the session

- Review the poll responses to understand audience preferences.
- Discuss recurring words in the word cloud.
- Use the scale aggregate to understand overall confidence.
- Review open-text suggestions and identify possible improvements.

## Results and visibility

- The facilitator (host) can see all question results throughout the session.
- During a live session, participants do not receive aggregate question results while the session is still running.
- Participants may see the leaderboard during a live question reveal, depending on the quiz's leaderboard settings.
- For scheduled sessions, a participant who has completed the quiz can access aggregate results even if the session is still open.
- After the session ends, participants can access results according to the quiz's answer-reveal and leaderboard policies.
- Correct-answer information is only shown when the answer-reveal policy permits it.
- The host can access the full results page and export results as CSV or JSON.

For this workshop, the facilitator should reveal each question, discuss the displayed aggregate with the group, and then move to the next question. Word-cloud entries, open-text responses, and scale averages are displayed on the host's reveal screen.

## Current capabilities and limitations

This recipe uses existing quiz question types and live-session participation.

It does not require or imply a dedicated classroom assignment workflow, learner enrollment system, assignment grading, or proctoring. These should be treated as separate capabilities, not as features demonstrated by this workshop.
